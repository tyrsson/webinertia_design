Default Modal

This is the default modal variant using the purple gradient accent bar. It inherits the site's dark glassmorphic aesthetic with a backdrop blur and a subtle purple border glow.

Use this pattern for general information dialogs, detail panels, or any non-critical interaction where a standard modal flow is appropriate.

Cyan Modal

The cyan variant uses the cyan-to-purple gradient accent bar and a cyan-tinted border glow. This works well for informational, discovery, or onboarding dialogs — anything that feels exploratory rather than critical.

Switch between variants by adding a modifier class — modal-cyan, modal-magenta, modal-danger, or modal-success — to the .modal element.
